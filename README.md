
# Данные проекта Guitar Fingering AI

Этот репозиторий содержит структуру данных, скрипты для их проверки и результаты baseline-оценки. 
Тяжелые видеофайлы намеренно **не хранятся в Git** (они лежат на Google Drive).

## Структура данных
```markdown

data/
├── meta.csv          # Метаданные о видео и эталонных MIDI
├── midi/             # Эталонные MIDI-файлы 
└── videos/           # Видеофайлы 
```

### 1. `meta.csv`
Содержит информацию о каждом клипе:
*   `id` — порядковый номер
*   `имя файла` — имя видеофайла 
*   `имя эталонного MIDI` — имя соответствующего MIDI-файла 
*   `пригодна` — флаг (`да`/`нет`), указывающий, можно ли использовать пару для оценки (есть ли эталонный MIDI и подходит ли видео)
*   и другие метаданные (инструмент, ссылка на источник и т.д.)


### 2. `data/midi/`
Содержит эталонные MIDI-файлы для пригодных пар. Имена файлов совпадают с колонкой `видео` в `meta.csv` (за исключением расширения).

### 3. `data/videos/`
Содержит исходные видеофайлы. **Эти файлы не коммитятся в Git** (добавлены в `.gitignore`).

## Скрипты
В папке `scripts/` лежат вспомогательные скрипты:
*   `check_data.py` — проверяет, что для всех пригодных пар из `meta.csv` на месте есть и видео, и MIDI.
    *   Запуск: `python scripts/check_data.py`
*   `run_baseline.py` — запускает backend на всех пригодных парах, сравнивает результаты с эталонными MIDI и считает метрики (Precision, Recall, F1). 
    *   Запуск: `python scripts/run_baseline.py` (требует запущенного backend-сервера).
