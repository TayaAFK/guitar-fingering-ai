# Guitar Fingering AI

Распознавание гитарной аппликатуры по видео с использованием ИИ: загружаешь видео с игрой на гитаре, получаешь MIDI-файл с нотами (высота и октава, начало, длительность, аккорды).

Заказчик: ООО «Цифровые решения». Программа 09.03.01 «Алгоритмы искусственного интеллекта», осенний семестр 2026/2027.

## Как это работает

- **Левая рука** определяет высоту: нота = открытая струна + лад.
- **Правая рука** определяет время: удар или щипок задаёт начало ноты и ритм.
- **Аудио** (если есть) страхует результат и уточняет ноты.

## Стек

ffmpeg, yt-dlp, MediaPipe Hands, OpenCV (затем YOLO при необходимости), CLIP, Basic Pitch, pretty_midi, PyTorch, FastAPI, React + Vite, pytest, GitHub Actions, Docker Compose (с конца MVP). Работает на CPU.

## Структура

```
backend/    API, аудио, MIDI
vision/     рука и гриф
frontend/   интерфейс (React + Vite)
data/       meta.csv, эталонные MIDI, разметка (видео в git не храним)
docs/       документация, user stories и use cases, формат нот
```

## API

| Метод | Адрес | Назначение |
|---|---|---|
| POST | `/upload` | загрузить видео, получить `task_id` |
| GET | `/status/{task_id}` | `queued` / `processing` / `done` / `error` |
| GET | `/result/{task_id}` | скачать .mid |

## Ограничения MVP

mp4 и mov, до 10 минут, до ~500 МБ. Ссылки YouTube, RuTube, VK — дополнительно. Без громкости и без квантизации по сетке.
