# Спецификация JSON-схемы данных видеотранскрипции (vision_schema.md)

Документ предназначен для согласования структуры данных с аудио- и бэкенд-модулями.

## Относительная сетка грифа:
- **U**: вдоль грифа от $0.0$ (порожек) до $1.0$ (конец грифа).
- **V**: поперёк грифа от $0.0$ (тонкая/нижняя струна) до $1.0$ (толстая/верхняя струна).

## Пример выходного JSON-файла:

```json
{
  "video_name": "test_video_1.mp4",
  "fps": 30.0,
  "frames": [
    {
      "frame_id": 45,
      "timestamp_ms": 1500,
      "neck_detected": true,
      "hand_detected": true,
      "fingers": {
        "index_tip": { "u": 0.25, "v": 0.80 },
        "middle_tip": { "u": 0.30, "v": 0.60 },
        "ring_tip":   { "u": 0.32, "v": 0.40 },
        "pinky_tip":  { "u": 0.35, "v": 0.20 }
      }
    }
  ]
}

Если гриф или рука не найдены, neck_detected / hand_detected принимают значение false, а поле fingers передается как null.
